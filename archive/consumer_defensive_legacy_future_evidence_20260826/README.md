# Consumer Defensive legacy protocol archive

Archived on 2026-08-26 as part of the Consumer Defensive v2 isolation.

These files implement the retired prospective-evidence/Stage12 route. They are
retained for audit and recovery only and are not admissible as v2 calibration,
promotion, orchestration, or Portfolio Layer evidence. Active Consumer code must
not import this directory. Transportation code was not moved or retired.

`MANIFEST.json` records every archived file, its original active path, byte size,
and SHA-256 digest. Restoring a file requires an explicit architecture decision;
copying it back does not make its evidence admissible under v2.
